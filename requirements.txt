# ---------------------------------------------------------------------------
# Install order and indexes. The Dockerfile does this in four separate steps
# and the order is load-bearing.
#
#   1. numpy first, pinned below 2. Isaac Sim's compiled ABI breaks on numpy 2
#      (README, "Why lerobot --no-deps?"). Installing it first means later
#      packages resolve against the pinned numpy instead of pulling numpy 2.
#
#   2. torch, from the CUDA 12.8 wheel index:
#        pip install "torch==2.7.0" \
#          --index-url https://download.pytorch.org/whl/cu128
#      That flag is NOT set in this file. As a requirements-file directive
#      --index-url applies to every line in the file, not just torch, which
#      would send the rest of the resolve to the PyTorch index too. Install
#      torch on its own line with the flag, exactly as Dockerfile lines 67-68
#      do.
#
#   3. isaacsim, from NVIDIA's index:
#        pip install "isaacsim[all,extscache]==5.1.0" \
#          --extra-index-url https://pypi.nvidia.com
#      Same reasoning. Kept out of this file, run as its own step. See
#      Dockerfile lines 73-74.
#
#   4. lerobot, with --no-deps. Its rerun-sdk dependency requires numpy >= 2,
#      which breaks Isaac Sim (README, "Why lerobot --no-deps?"). --no-deps is
#      a global pip flag with no per-requirement form, so it cannot be attached
#      to a single line here. See Dockerfile line 100.
# ---------------------------------------------------------------------------
